- containerd との統合
  - Docker Daemon と containerd ランタイムの間の抽象化層
  - containerd API へのアクセスを提供
- コンテナライフサイクル管理
  - コンテナの作成、起動、停止、削除、一時停止/再開などのライフサイクル操作を管理
- イベント処理
  - containerd からのイベントを受け取り、上位の Backend に通知するイベントストリーム
- タスク・プロセス管理
  - コンテナ内のタスクやプロセスの実行、監視、標準入出力の接続、リソース更新
- プラットフォーム抽象化
  - Linux と Windows それぞれの実装を提供し、プラットフォーム固有の詳細を隠蔽
