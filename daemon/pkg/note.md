- daemon で使用される複数のサブシステムを提供するユーティリティパッケージ
  - oci
    - OCI Runtime Spec 生成
    - コンテナ実行のための OCI 仕様を生成
  - opts
    - CLI オプション解析とバリデーション
    - daemon 起動時のコマンドラインオプションをパース・検証
  - plugin
    - Docker プラグインシステム
    - V2 プラグインのライフサイクル管理
      - pull、enable、disable、remove
    - プラグインストアの管理
    - レジストリからのフェッチ
    - コンテナとしてのプラグイン実行
  - registry
    - コンテナレジストリ連携
    - Docker Hub 等のイメージレジストリとの通信を管理
