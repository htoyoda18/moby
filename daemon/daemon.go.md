- 概要
  - Docker デーモンのコア実装
  - デーモンの状態管理、初期化、シャットダウンなどの中心的な機能を担当
- 処理の詳細
  - Daemon 構造体
    - Docker デーモンのすべての状態を保持する中心的な構造体
  - configStore 構造体
    - 設定とランタイム情報を保持
  - NewDaemon
    - デーモンの初期化処理
    - 処理の流れ
      - システム要件チェック
      - レジストリサービス初期化
      - 設定検証
      - リソース制限設定
      - 一時ディレクトリ準備
      - ランタイム設定
      - Daemon 構造体作成
      - Containerd クライアント作成
      - プラグイン管理初期化
      - イメージストア初期化
      - ボリュームサービス初期化
      - ネットワークコントローラー初期化
      - コンテナストア初期化
      - イベントサービス初期化
      - 既存コンテナの復元
      - 各種バックグラウンドタスク起動
  - restore
    - コンテナの復元
    - デーモン再起動時に既存コンテナを復元
  - RestartSwarmContainers
    - Swarm コンテナの再起動
    - Swarm クラスタ初期化後、Swarm 関連コンテナを再起動
  - Shutdown
    - デーモンの優雅なシャットダウン
    - 処理の流れ
      - LiveRestore 有効なら実行中コンテナはそのまま
      - すべてのコンテナを停止
      - ボリュームサービス停止
      - イメージサービスクリーンアップ
      - クラスタからの離脱
      - プラグインシャットダウン
      - NRI シャットダウン
      - ネットワークコントローラー停止
      - Containerd クライアントクローズ
      - イベントサービスクローズ
      - マウントクリーンアップ
  - Mount
    - コンテナのマウント
    - コンテナのレイヤーをマウントして BaseFS を設定
  - Unmount
    - コンテナのアンマウント
  - Config
    - 設定取得
  - Features
    - 機能フラグ取得
