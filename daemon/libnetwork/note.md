- Docker のコンテナネットワーキングを実装する中核パッケージ
  - ネットワーク名前空間の管理
    - コンテナごとに独立したネットワーク名前空間を作成・管理
  - 仮想ネットワークの制御
    - bridge、overlay、host など複数のネットワークドライバーを統一的に扱う抽象化レイヤー
  - エンドポイント管理
    - コンテナとネットワークを接続する論理的な接続点の作成・削除
  - IP アドレス管理
    - ネットワークごとの IP アドレス割り当て・サブネット管理を行う IPAM ドライバーの統合
  - DNS 解決
    - コンテナ内部でのサービス名解決、組み込み DNS リゾルバー
  - ポートマッピング
    - ホストとコンテナ間のポート公開・転送ルールの設定
  - サービスディスカバリー
    - Swarm モードでのサービス名から VIP/IP への名前解決とロードバランシング
  - ファイアウォール制御
    - iptables/nftables を使ったネットワークルールの設定・管理
  - マルチホストネットワーク
    - Swarm クラスター内でのオーバーレイネットワーク構築
  - 永続化
    - ネットワーク設定の保存・復元をデータストア経由で管理
