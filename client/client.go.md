- 概要
  - Docker クライアントの心臓部と言える重要なファイル
- API バージョンネゴシエーション
  - クライアントとサーバー（Docker Engine）の API バージョンに差分がある場合に、両者が通信できる共通のバージョンを自動的に選択する仕組み
- 内部実装
  - New
    - クライアントの初期化
    - 初期化の流れ
      - デフォルト設定の構築
      - オプション適用
      - API バージョン設定
      - トランスポート設定
  - defaultHTTPClient
  - checkVersion
  - negotiateAPIVersion
    - サーバーバージョンの検証
    - ネゴシエーション開始バージョン決定
    - サーバーが古い場合はダウングレード
    - 結果を保存
  - getAPIPath
    - リクエストパス生成
  - CheckRedirect
    - POST が GET に変換される問題への対処らしい
  - dialer
  - Close
